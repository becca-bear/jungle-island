# Jungle Island

A procedural 3D island sandbox that runs from a single `index.html` (three.js r128, loaded from a CDN). Open the file in a browser and play.

The island is generated from real-Earth coastline, relief and Köppen climate data, so the biomes, weather and seasons follow the place you pick.

## Features
- Explore jungle, swamp, savanna, desert, alpine and snow biomes, volcanoes, rivers and the open sea
- Swim and dive, ride horses and sail ships, visit the underwater merfolk city
- Day/night cycle, weather and a 28-day calendar with four seasons
- A cobblestone town with shops, an enterable bakery and museum, and your own home with furniture and a wardrobe
- Farming with season-dependent crops
- Caves to mine rocks, ores and crystals, with small monsters to fight
- Fishing and bug-catching, plus a museum to donate fish, insects, meteorites and gems
- Villagers and merfolk follow daily routines (farming, fishing, shopping, sheltering from rain, sleeping)

## Controls
WASD move · Shift run · E interact · Q swing (in the mine) · I pack · M map · J quests · C character · F torch

## Run
Open `index.html` in a modern browser. No build step.
